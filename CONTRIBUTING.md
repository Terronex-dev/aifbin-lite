# Contributing

AIF-BIN Lite is a **reference implementation**, not a community project.

## Bug Reports

Found a bug? [Open an issue](https://github.com/Terronex-dev/aifbin-lite/issues) with:
- Description of the problem
- Steps to reproduce
- Python version and OS

## Feature Requests

Most features belong in [AIF-BIN Pro](https://terronex.dev), our commercial product with semantic search, and integrations.

If you have a suggestion for Lite, open an issue — but note that Lite is intentionally minimal.

## Format Changes

The AIF-BIN specification is maintained by Terronex.dev. We do not accept pull requests that modify the format.

## Questions?

- **Issues** — For bugs
- **support@terronex.dev** — For everything else
