# Contributing to AIF-BIN Lite

Thank you for your interest in contributing!

## How to Contribute

### Reporting Bugs

1. Check existing [Issues](https://github.com/terronexdev/aifbin-lite/issues)
2. Create a new issue with:
   - Clear description
   - Steps to reproduce
   - Python version and OS

### Pull Requests

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Test thoroughly
5. Submit a PR with clear description

### Code Style

- Python 3.8+ compatible
- Type hints encouraged
- Clear docstrings
- No external dependencies for v1 (keep it lite!)

## Project Structure

```
aifbin-lite/
├── aifbin_v1.py      # v1 JSON format (no dependencies)
├── aifbin_v2.py      # v2 binary format (requires msgpack)
├── examples/         # Usage examples
└── legal/            # Legal documents
```
